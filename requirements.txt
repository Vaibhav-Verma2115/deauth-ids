# ---------------------------------------------------------------------------
# Pinned so the shipped models/model.pkl loads.
#
# model.pkl is a pickle of a scikit-learn RandomForestClassifier, and a pickle
# is only guaranteed to load under the library versions that wrote it:
#
#   * scikit-learn is pinned exactly. Loading an estimator pickled by a
#     different version raises InconsistentVersionWarning and can fail
#     outright, because the pickle stores the fitted attributes of that
#     version's classes.
#   * numpy must stay on 2.x. NumPy 2.0 renamed the internal `numpy.core`
#     module to `numpy._core`, so a 2.x pickle hits ModuleNotFoundError on
#     NumPy 1.x. Any 2.x release can read a 2.x pickle, so this is a range
#     rather than an exact pin -- that keeps newer Pythons installable, since
#     numpy 2.0.2 has no wheels for Python 3.13+.
#
# If these cannot be satisfied on your machine, nothing is lost: delete
# models/ and retrain in about a minute with `python src/train_model.py`, or
# press "Run 1 -> 2" on the dashboard's Model & Dataset tab.
# ---------------------------------------------------------------------------

numpy>=2.0,<3
scipy>=1.11
